# Contributing

ByteDistill is preparing its initial code release. Documentation corrections and questions about the method are welcome through [GitHub Issues](https://github.com/Piplup0924/ByteDistill/issues).

For a documentation change, open a focused pull request explaining what changed and why. When correcting a reported result or method description, include a public reference or a reproducible example.

After runnable code is released, bug reports should identify the repository revision, relevant package versions, expected behavior, and a minimal example. Installation commands and supported environments will be documented with that release.

Please use public or synthetic examples. Remove credentials, personal information, private dataset records, internal endpoints, and local infrastructure details before posting logs or configuration files.

Contributions are made under the repository's [Apache-2.0 license](LICENSE).
